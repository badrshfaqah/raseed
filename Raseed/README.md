# الصفحة التعريفية لبرنامج رصيد (One Page)

صفحة تعريفية مستقلة وجاهزة للرفع المباشر على موقع المجرات أو أي استضافة.

## المحتوى
```
Raseed/
├── index.html          الصفحة التعريفية الرئيسية (16 قسماً)
├── about.html          صفحة "عن البرنامج" التفصيلية
├── README.md           هذا الملف
└── assets/
    ├── css/style.css   التصميم الكامل (هوية خضراء حديثة، RTL)
    ├── js/main.js      حركات الظهور، القائمة، سلوك الهيدر
    ├── fonts/          خط Noto Sans Arabic مضمّن (يعمل بلا إنترنت)
    └── img/
        ├── logo.png        الشعار الرسمي
        ├── cover.png       صورة الغلاف (للسوشال/OG)
        ├── favicon.png     أيقونة الموقع
        └── screens/        لقطات واجهات النظام (WebP)
```

## كيف ترفعها
انسخ مجلد `Raseed` كما هو إلى استضافتك، وافتح `index.html`. الصفحة تعمل بشكل مستقل تماماً (الخطوط مضمّنة، وخط Tajawal يُحمّل تلقائياً من Google Fonts عند توفّر الإنترنت لمظهر أجمل).

## الروابط التي تحتاج تعديلها (سهلة)
ابحث في `index.html` عن التعليقات التي تبدأ بـ `✏️`:

1. **رابط التحميل**: في قسم التحميل، السطر `<a href="#" ... id="downloadBtn">` — ضع رابط ملف التحميل بدل `#`.
2. **رابط التواصل/التخصيص**: `<a href="https://ar.almgrat.com/contact" ...>` — عدّله لصفحة التواصل الصحيحة.
3. **روابط المجرات في الفوتر**: `https://ar.almgrat.com`.

## ملاحظة عن الهوية
بُنيت الصفحة بالهوية الخضراء المتناسقة مع شعار «رصيد» بأسلوب عصري (Notion/Stripe). إن أردت مطابقة ألوان موقع المجرات بدقة، غيّر متغيرات الألوان في أعلى `assets/css/style.css` (مثل `--green-600`).
